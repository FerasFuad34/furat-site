# 🌊 موقع الفرات الحلوة لتحلية المياه

موقع كامل + لوحة تحكم ديناميكية — مبني بـ Node.js / Express.
النصوص كلها باللهجة السعودية البيضاء، والتصميم خاص 100% (شعار + هوية + رسومات منتجات مولّدة بالكود).

---

## التشغيل المحلي

```bash
cd furat-site
npm install          # مرة واحدة فقط
npm start            # ثم افتح http://localhost:3000
```

| الرابط | الوصف |
|---|---|
| `/` | الموقع |
| `/admin` | لوحة التحكم — **الرمز الافتراضي: `1234`** |
| `/admin/login` | صفحة الدخول |
| `/api/data` | كل بيانات الموقع بصيغة JSON (لأي تكامل مستقبلاً) |
| `/sitemap.xml` · `/robots.txt` | جاهزة لمحركات البحث |

**تغيير المنفذ:** `PORT=8080 npm start`

---

## 🔐 الدخول للوحة التحكم (مهم)

المصادقة تعمل **بالتوكن** (يُحفظ في متصفحك) + كوكي احتياطي — تشتغل في كل الظروف،
حتى داخل إطارات المعاينة والجوال.

1. افتح `/admin/login`
2. أدخل الرمز `1234` (الافتراضي)
3. **أول شي تسويه: غيّر الرمز** من تبويب «بيانات الموقع» ← بطاقة «رمز دخول اللوحة»
   - الرمز الجديد يُحفظ مشفّراً (hash) في ملف `admin-auth.json` — لا يظهر أبداً في الموقع ولا في API
   - تظهر لك لافتة تحذير حمراء في اللوحة ما دمت تستخدم الرمز الافتراضي

**خروج طارئ:** احذف `admin-auth.json` من المجلد فيرجع الرمز إلى `1234` (أو قيمة `FH_PIN`).

## 📦 النسخة المستقلة (ملف واحد)

من داخل اللوحة: زر **«📦 نسخة مستقلة»** (أعلى الشاشة) — ينزّل ملف HTML واحد (~715KB)
فيه الموقع كامل بكل صفحاته ومنتجاته ورسوماته، يفتح بأي متصفح **بدون سيرفر وبدون إنترنت**.
مفيد للإرسال على واتساب لصاحب المحل يفتحه من جواله مباشرة.

> ملاحظة: النسخة المستقلة للعرض فقط — الطلبات تروح واتساب، لكن تعديل المنتجات يحتاج اللوحة على السيرفر.

---

## 💾 البيانات والنسخ الاحتياطي

- كل المحتوى في ملف واحد: `data.json` (إعدادات، منتجات، خدمات، باقات، آراء، أسئلة)
- كل حفظ يعمل نسخة احتياطية تلقائية: `data.json.bak`
- زر **«⬇ تصدير JSON»** في اللوحة ينزّل نسخة من بياناتك — **سوّيها أسبوعياً واحتفظ فيها خارج السيرفر**
- أي تعديل باللوحة يظهر في الموقع فوراً بعد الحفظ — بدون إعادة نشر

## 👥 سجل العملاء وتذكيرات الصيانة (CRM)

النظام يتذكر عن صاحب المحل كل مواعيد تغيير فلاتر عملائه — تلقائياً:

- من اللوحة: تبويب **«العملاء والتذكيرات»** — أضف العميل باسمه وجواله وجهازه وسجل تواريخ آخر تغيير لكل قطعة (شمعات أولية / شمعة نهائية / ممبرين).
- النظام يحسب موعد الاستحقاق وحده: آخر تغيير + دورة القطعة (افتراضياً: أولية 6 أشهر، نهائية 12 شهر، ممبرين 24 شهر — قابلة للتعديل من نفس التبويب).
- لوحة الأولويات: 🔴 متأخرون / 🟡 استحقاق خلال 30 يوم / 🟢 سليمين — مرتّبة بالأقرب أولاً، مع بحث وفلاتر وتصدير CSV (يفتح بإكسل).
- **«💬 تذكير واتساب»**: يفتح واتساب العميل برسالة جاهزة بالعامية: «آخر تغيير لـ X كان بتاريخ Y وصار موعد تغييرها…» — بضغطة واحدة.
- **«✓ تم التغيير»**: بعد زيارة الصيانة تضغطها فيصفّر العداد وتبدأ دورة جديدة — السجل يعيش ويكبر مع المحل.
- شارة حمراء على التبويب تعرض عدد المتأخرين — تفتح اللوحة وتشوف وش يلزمك اليوم بدون مراجعة دفاتر.

**الخصوصية:** سجل العملاء في ملف منفصل `customers.json` لا يُنشر أبداً:
ما يظهر في الموقع، ولا في `/api/data`، ولا في النسخة المستقلة — protected بنفس مصادقة اللوحة، ومع كل حفظ نسخة `customers.json.bak`.

## 🚀 النشر على استضافة حقيقية (لصاحب المحل)

### الخيار الأسهل: Render.com (مجاني للبداية)
الملف `render.yaml` جاهز — نشر بضغطة زر:
1. ارفع مجلد `furat-site` على GitHub (مستودع خاص)
2. في Render: **New → Blueprint** → اختر المستودع → يقرأ `render.yaml` وينشر وحده
3. الخطة المجانية تنام بعد 15 دقيقة خمول — فعّل حساب مجاني على **UptimeRobot** وأضاف monitor على رابط الموقع (كل 5 دقائق) عشان تبقى صاحية 24/7
4. **مهم:** قرص الخطة المجانية مؤقت — `data.json` و`customers.json` يرجعان لنسخة المستودع مع كل نشر جديد. حلان:
   - فعّل Disk مدفوع (~$1/شهر) = بيانات دائمة ← **الأنسب لمحل حقيقي**
   - أو صدّر JSON دورياً من اللوحة وأعد رفعه (يكفي لمرحلة التجربة)

### خيارات بديلة
- **Railway.app** — نفس الفكرة، يدعم Volumes بشكل أسهل (~$5/شهر)
- **VPS** (Hostinger/DO بـ 5$ شهرياً) — تحكم كامل: `git clone && npm install && pm2 start server.js` مع Nginx + شهادة SSL مجانية (Let's Encrypt)

### بعد النشر — checklist SEO
1. اشترِ نطاق (مثل `furat-alhalw.sa` أو `.com`) واربطه بالاستضافة
2. فعّل HTTPS (إجباري — الاستضافات أعلاه توفره مجاناً)
3. سجّل الموقع في **Google Search Console** وأضف `sitemap.xml`
4. أنشئ ملف **Google Business Profile** للمحل (مهم جداً للبحث المحلي "تحلية مياه الرياض")
5. الموقع يولّد تلقائياً: canonical + og:url + og:image بالنطاق الكامل، وبيانات منظمة JSON-LD (LocalBusiness + Product) — كلها جاهزة للفهرسة

## 🗂️ هيكل المشروع

```
furat-site/
├── server.js            # Express: الصفحات + API + لوحة التحكم + التصدير
├── data.json            # كل المحتوى (المصدر الوحيد للحقيقة)
├── admin-auth.json      # يُنشأ تلقائياً عند تغيير الرمز (مشفر)
├── lib/
│   ├── render.js        # توليد صفحات HTML كاملة من data.json (SSR)
│   └── art.js           # رسومات المنتجات SVG مولّدة بالكود
├── admin/
│   ├── login.html       # صفحة الدخول
│   └── index.html       # اللوحة (10 تبويبات + قائمة تحقق قبل التسليم)
└── public/assets/       # CSS + JS + الشعارات + أيقونات PWA
```
